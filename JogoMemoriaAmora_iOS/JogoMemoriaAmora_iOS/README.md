# Jogo de Memória da Amora — iOS

Versão iOS baseada no mesmo jogo HTML do Android. Funciona offline com as 8 fotos.

## Abrir no iPhone
1. Em um Mac, instale/abra o Xcode.
2. Abra `JogoMemoriaAmora.xcodeproj`.
3. Selecione seu iPhone ou um simulador.
4. Em Signing & Capabilities, selecione sua Apple Account/Team.
5. Pressione Run (▶).

A publicação na App Store exige uma conta Apple Developer e configuração no App Store Connect.
